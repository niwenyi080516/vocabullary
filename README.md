# vocabullary · 背单词

一个单文件的英语背单词应用。打开 `index.html` 就能用，不需要安装、不需要构建、不需要联网（发音除外）。

内置艾宾浩斯间隔重复排期、三档自评、选择题测验、学习统计和自定义词表导入。

## 功能

- **间隔重复**：复习节点为第 1、2、4、7、15、30、60、120 天。自评「认识」往后推一档，「有点模糊」保留当前档位并在 10 小时后重来，「不认识」回到第 1 档并在 10 分钟后重来。
- **每日新词上限**：默认 20 个，可在设置里调（5–60）。**按词书独立计算**，切换词书不会互相占用额度。
- **三档自评 + 撤销**：点「认识」后 3.5 秒内可以点提示条上的「撤销」（或 `Ctrl/Cmd + Z`）回退这次评分，排期和今日计数一起还原。
- **选择题测验**：从已学词里抽 10 个，中英双向出题，四选一。
- **统计**：当前词书已学 / 已掌握 / 连续打卡 / 全部词书累计，最近 7 天柱状图，各词书进度条。
- **自定义词表**：弹层里粘贴导入，支持逐条删除和全部清空。
- **发音**：浏览器 `speechSynthesis`，可选自动朗读、可调语速。
- **深色模式**：跟随系统。

## 使用

```bash
# 方式一：直接双击
index.html

# 方式二：本地起个静态服务（避免 file:// 下的 localStorage 限制）
python -m http.server 8000
# 然后打开 http://127.0.0.1:8000/
```

部署到 GitHub Pages 也可以，直接把 `index.html` 放到 Pages 根目录即可。

## 词条格式

内置词书和自定义词表共用同一种格式，竖线分隔：

```
单词|音标|释义|例句|词性
abandon|/əˈbændən/|to leave somebody or something and never come back|They had to abandon the plan.|v.
```

- 只有「单词」和「释义」是必填的，音标、例句、词性可以留空。
- 也支持简写：`abandon to leave somebody for ever`（空格或逗号分隔，只有单词和释义）。
- 释义为英文定义，未提供中文释义。

## 数据存储

- 全部状态存在 `localStorage` 的 `dsword.v1` 键下：设置、自定义词表、每个词的学习进度、每日学习记录、打卡连续天数。
- **没有云端同步，也没有导出功能**。清理浏览器数据会丢失全部进度。
- 设置里可以「清空当前词书进度」或「清空我的词表」，两个操作都是不可恢复的。

## 实现说明

整个应用是一个 `index.html`：约 208 行 CSS、13 行 HTML 骨架、约 6000 行内联词库数据、约 750 行逻辑，逻辑全部由一个立即执行函数封装。

没有框架、没有构建步骤、没有运行时依赖。改完直接刷新页面即可。

关键常量在脚本的「基础」段：

```js
const IV = [0,1,2,4,7,15,30,60,120];  // 复习间隔（天）
const MASTER = 4;                       // s >= 4 视为已掌握
const STORE = 'dsword.v1';              // localStorage 键名
```
